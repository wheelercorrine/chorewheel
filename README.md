# Chore Wheel

A wheel-of-fortune style chore picker built with React and Vite. Spin the wheel to get a random chore, then mark it complete to remove it from the wheel.

## Features

- Spin the wheel to pick a chore at random
- Add, edit and complete chores from the list
- Completed chores are removed from the wheel
- Keyboard operable controls, screen reader announcements and a reduced-motion fallback
- Muted color theme designed to meet WCAG 2.2 AA contrast

## Run locally

Requires [Node.js](https://nodejs.org/) 18 or later.

```sh
npm install
npm run dev
```

Open the URL printed in the terminal (usually http://localhost:5173).

## Other scripts

- `npm run build` creates a production build in `dist/`
- `npm run preview` serves the production build locally
- `npm run lint` runs ESLint
